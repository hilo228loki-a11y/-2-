# Лабораторная 4.2 — GUI для структуры данных «Очередь»

Оконное приложение на Python (tkinter), визуализирующее очередь из лабораторной 4.1 (вариант 1).
Все операции с очередью выполняются только через отдельные модули.

## Структура

| Файл | Назначение |
|---|---|
| `queue_dyn.cpp` | C++ модуль №1: очередь на динамической памяти (односвязный список, Head/Tail/Count) |
| `queue_stl.cpp` | C++ модуль №2: очередь на адаптере STL `std::queue<int>` |
| `queue_py.py` | Python модуль: очередь на связном списке |
| `queue_cpp.py` | Обёртка `ctypes` над C++ библиотеками |
| `backends.py` | Фабрика реализаций (GUI знает только `create_queue()`) |
| `app.py` | GUI на tkinter |
| `test_backends.py` | Одинаковые тесты для всех реализаций |
| `Makefile`, `build.bat` | Сборка C++ библиотек |

## Сборка и запуск

Linux/macOS/MinGW:
```
make
python app.py
```
Windows (MinGW-w64, g++ в PATH; разрядность g++ и Python должна совпадать):
```
build.bat
python app.py
```
Тесты: `python test_backends.py`

Если библиотека не собрана, соответствующий пункт просто не появится в списке реализаций.

## Возможности

- Enqueue / Dequeue / Peek / Clear, ввод по Enter.
- Выбор реализации «на лету» (данные переносятся в новую реализацию).
- Отрисовка очереди на Canvas: элементы, стрелки, указатели Front и Rear, подсветка при Peek, прокрутка.
- Журнал операций и строка состояния.
- Некорректные операции (Dequeue/Peek из пустой очереди, не-число, пустой ввод, переполнение int32) показывают понятное сообщение без падения.
